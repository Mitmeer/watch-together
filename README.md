# Watch Together

Сайт для совместного просмотра видео в реальном времени.

## Как открыть САЙТ и отправить другу

1. Дважды нажмите **`Watch Together - САЙТ.bat`** на рабочем столе  
   (или **`start-site.bat`** в папке проекта)
2. Появится **публичная ссылка** вида `https://....trycloudflare.com`
3. **Отправь эту ссылку другу** — он откроет её в браузере как обычный сайт
4. Ссылка также сохраняется в **`Watch Together - ССЫЛКА.txt`** на рабочем столе

> Пока работает окно туннеля — сайт доступен из интернета.  
> Не закрывайте его, пока друг смотрит видео.

## Первая установка

Дважды нажмите **`install.bat`** — установит всё автоматически.

## Адреса

| Кому | Ссылка |
|------|--------|
| Тебе (на этом ПК) | http://localhost:3001 |
| Другу (из интернета) | ссылка из `start-site.bat` |
| Другу (в одной Wi‑Fi) | http://10.33.0.2:3001 |

## Как пользоваться

1. Введите имя → **Создать комнату**
2. Нажмите **Пригласить друга** — скопируется ссылка
3. Друг открывает ссылку или вводит код комнаты
4. Хост вставляет ссылку на видео → **Загрузить**
5. Смотрите синхронно, общайтесь в чате

## Что установлено

- **Node.js** — сервер и клиент
- **yt-dlp** — извлечение видео (YouTube, VK, Rutube и др.)
- **FFmpeg** — обработка видео
- **Персонажи на фоне** — Mortis, Angela, Maelstroy, Taksa, Lelouch, C.C.

## Команды

```bash
npm run install:all   # Установка зависимостей
npm run setup:python  # yt-dlp через uv
npm run build         # Сборка production
npm run start:prod    # Сборка + запуск production
npm run dev           # Режим разработки
```

## Docker (опционально)

```bash
docker compose up --build
```

Сайт будет на http://localhost:3001

## Структура

```
├── server/           Express + Socket.io + yt-dlp
├── client/           React + Vite
├── client/public/characters/  Изображения персонажей
├── install.bat       Полная установка
├── start.bat         Запуск production
├── start-dev.bat     Запуск для разработки
├── Dockerfile        Docker-образ
└── .venv/            Python + yt-dlp
```

## Примечания

- Управление плеером только у хоста (создателя комнаты)
- При выходе хоста роль передаётся другому участнику
- Для VK/YouTube обновляйте yt-dlp: `uv pip install -U yt-dlp`
- Чтобы друг подключился из интернета — нужен проброс порта 3001 на роутере или VPS
